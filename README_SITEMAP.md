Pilih salah satu metode:
- **HTML File** (termudah) ⭐
- **Meta Tag** (recommended)
- **DNS Record** (paling permanen)

Lihat: `CONTOH_VERIFIKASI_GOOGLE.md`

### Step 4: Submit Sitemap
1. Login ke [Google Search Console](https://search.google.com/search-console)
2. Pilih property Anda
3. Klik menu "Sitemaps"
4. Masukkan: `sitemap.xml`
5. Klik "Submit"

- Coverage report (halaman terindex)
- Performance report (traffic dari Google)
- Mobile usability (mobile-friendly check)

## 🎯 Tips Sukses

### 1. Konten Berkualitas
- Tulis artikel minimal 500 kata
- Update konten secara rutin
- Gunakan heading (H1, H2, H3) dengan benar

### 2. Optimasi Gambar
- Compress gambar (max 200KB)
- Tambahkan alt text
- Gunakan nama file yang SEO-friendly

### 3. Kecepatan Website
- Gunakan caching
- Minify CSS/JS
- Lazy load images

### 4. Mobile-Friendly
- Responsive design (sudah ada!)
- Font size minimal 16px
- Touch targets minimal 48x48px

### 5. Internal Linking
- Link antar halaman yang relevan
- Gunakan anchor text deskriptif
- Breadcrumb navigation

## ⚠️ Troubleshooting

### Sitemap Tidak Terdeteksi
- Tunggu 24-48 jam
- Submit ulang sitemap
- Cek format XML (harus valid)

### Halaman Tidak Terindex
- Request indexing via URL Inspection
- Cek robots.txt (jangan block)
- Pastikan halaman bisa di-crawl

### Error 404/500
- Cek Laravel error log
- Pastikan route tidak berubah
- Clear cache Laravel
