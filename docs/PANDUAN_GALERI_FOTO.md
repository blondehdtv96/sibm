# Panduan Menggunakan Galeri Foto Berita

## 📸 Untuk Admin Panel

### Menambah Berita dengan Galeri Foto

1. **Buka Admin Panel** → Klik **"Berita"** di sidebar
2. **Klik Tombol "Create News"** atau **"+ Buat Berita Baru"**
3. **Isi Form Dasar:**
   - Title (Judul)
   - Slug (auto-generate)
   - Excerpt (preview teks)
   - Content (isi lengkap artikel)
   - Category (pilih kategori)
   - Status (Draft atau Published)

4. **Unggah Featured Image** (gambar utama):
   - Klik "Choose File" di section "Featured Image"
   - Pilih 1 gambar ukuran max 2MB
   - Preview akan tampil otomatis

5. **Unggah Gallery Images** (galeri foto):
   - Scroll ke section **"Gallery Images"**
   - Klik "Choose Files" di input "Images"
   - **Pilih BANYAK foto sekaligus** (Ctrl+Click atau Shift+Click)
   - Preview grid akan tampil untuk setiap foto
   - **(OPSIONAL)** Tambah caption di textbox dibawah masing-masing preview

6. **Simpan** dengan klik tombol **"Create Article"**

### Mengedit Berita & Galeri Foto

1. **Buka Admin Panel** → **Berita**
2. **Klik Edit** pada berita yang mau diubah
3. **Lihat Section "Current Gallery":**
   - Tampil semua foto yang sudah diupload
   - **Hover** di atas foto
   - **Klik tombol Trash/Delete** untuk hapus foto individual
4. **Tambah Foto Baru:**
   - Scroll ke "Add Images"
   - Upload foto baru seperti saat create
5. **Simpan** dengan klik **"Update Article"**

### Menghapus Berita

1. **Berita** → Cari artikel yang mau dihapus
2. Klik tombol **Delete** (🗑️ icon)
3. Confirm penghapusan
4. ✅ Semua foto galeri otomatis terhapus

---

## 👁️ Untuk Pengunjung Website

### Melihat Galeri Foto

1. **Cari Berita** yang ingin dibaca di halaman Berita
2. **Klik Title** atau **"Baca" button** untuk buka detail
3. **Scroll ke bawah** untuk lihat section **"Galeri Foto"**
4. **Lihat Grid Foto:**
   - Gambar ditampilkan dalam grid rapi
   - **Hover** di atas foto untuk efek hover:
     - Gambar membesar
     - Overlay gelap
     - Caption tampil (jika ada)
     - Icon zoom tampil
5. **Klik Gambar** untuk lihat full-size (siap untuk lightbox di update berikutnya)

---

## 📝 Catatan Penting

✅ **File Yang Diperbolehkan:** JPG, JPEG, PNG, GIF  
✅ **Ukuran Max Per File:** 2 MB  
✅ **Jumlah Foto:** Unlimited (tidak ada batasan jumlah)  
✅ **Caption:** Opsional, bisa dikosongkan

⚠️ **Penting:**
- Pastikan foto sudah berkualitas sebelum upload
- Gunakan nama file yang deskriptif
- Caption membantu pembaca memahami isi foto

## 🎨 Contoh Penggunaan

### Berita "Acara Wisuda 2025"
```
Featured Image: Foto utama wisuda (1 gambar)
Gallery Images:
- Foto rektorat (caption: "Rektor memberikan ijazah kepada lulusan")
- Foto mahasiswa (caption: "Mahasiswa merayakan kelulusan")
- Foto keluarga (caption: "Kebersamaan keluarga dan almamater")
- Foto grup (caption: "Seluruh keluarga besar wisudawan 2025")
```

Website akan tampil:
- Headline dengan featured image
- Artikel deskripsi acara
- **Galeri Foto** dengan 4 gambar dalam grid
- Hover di foto → lihat caption

## ❓ FAQ

**P: Berapa banyak foto yang bisa diupload?**  
J: Unlimited, tidak ada batasan jumlah foto per artikel.

**P: Bisakah edit caption setelah upload?**  
J: Belum bisa (fitur akan ditambah). Untuk sekarang, hapus foto dan upload ulang.

**P: Bagaimana kalau lupa upload foto?**  
J: Tidak masalah, bisa edit berita nanti dan tambah foto baru di section "Add Images".

**P: Foto bisa dihapus satu-satu?**  
J: Ya, di halaman edit, hover foto existing dan klik tombol delete.

**P: Apakah order foto bisa diubah?**  
J: Belum bisa di-reorder. Foto ditampilkan sesuai urutan upload. (Fitur akan ditambah)
