## 🏠 MENGELOLA HOME SLIDER

### Menambah Slider Baru

1. **Klik** "Home Slider" di sidebar
2. **Klik** tombol "Tambah Slider"
3. **Upload** gambar (recommended: 1920x1080px)
4. **Isi** form:
   - **Title**: Judul utama (opsional)
   - **Subtitle**: Deskripsi (opsional)
   - **Button Text**: Text tombol CTA (opsional)
   - **Button Link**: URL tujuan tombol (opsional)
   - **Order**: Urutan tampil (angka kecil = tampil duluan)
   - **Status**: Aktif/Nonaktif
5. **Klik** "Simpan"

### Tips Slider
- ✅ Gunakan gambar berkualitas tinggi
- ✅ Ukuran ideal: 1920x1080px (16:9)
- ✅ File size: maksimal 500KB
- ✅ Format: JPG atau PNG
- ✅ Maksimal 5-7 slider aktif
- ✅ Gunakan text yang singkat dan jelas

### Mengedit Slider

1. **Klik** icon pensil di slider yang ingin diedit
2. **Update** informasi yang diperlukan
3. **Upload** gambar baru (jika perlu)
4. **Klik** "Update"

### Menghapus Slider

1. **Klik** icon trash di slider yang ingin dihapus
2. **Konfirmasi** penghapusan
3. Slider akan dihapus permanen

## 🎓 MENGELOLA PROGRAM KEAHLIAN

### Menambah Program Baru

1. **Klik** "Program Keahlian" di sidebar
2. **Klik** "Tambah Program"
3. **Isi** form:
   - Nama program
   - Deskripsi
   - Fasilitas
   - Status
4. **Upload** gambar utama
5. **Klik** "Simpan"

### Menambah Gambar Program

1. **Buka** detail program keahlian
2. **Klik** tab "Gambar"
3. **Klik** "Tambah Gambar"
4. **Upload** gambar
5. **Isi** caption (opsional)
6. **Set** urutan
7. **Klik** "Simpan"

### Tips Program Keahlian
- ✅ Upload minimal 3-5 gambar per program
- ✅ Gunakan foto fasilitas dan kegiatan
- ✅ Tulis deskripsi yang informatif
- ✅ Update secara berkala

## 📋 MENGELOLA PPDB

### Melihat Pendaftar Baru

1. **Klik** "PPDB" → "Pendaftaran"
2. **Lihat** daftar pendaftar
3. **Klik** nama untuk detail lengkap

### Memproses Pendaftaran

1. **Buka** detail pendaftar
2. **Review** data dan dokumen
3. **Update** status:
   - Pending
   - Diverifikasi
   - Diterima
   - Ditolak
4. **Kirim** notifikasi ke pendaftar

### Export Data Pendaftar

1. **Klik** tombol "Export"
2. **Pilih** format (Excel/PDF)
3. **Download** file

### Tips PPDB
- ✅ Cek pendaftar baru setiap hari
- ✅ Verifikasi dokumen dengan teliti
- ✅ Update status secara berkala
- ✅ Kirim notifikasi ke pendaftar

## 💬 MENGELOLA CHATBOT

### Menambah Response Baru

1. **Klik** "Chatbot" → "Responses"
2. **Klik** "Tambah Response"
3. **Isi** form:
   - **Keywords**: kata kunci (pisahkan dengan koma)
   - **Response**: jawaban chatbot
   - **Category**: kategori pertanyaan
   - **Priority**: prioritas (angka besar = prioritas tinggi)
4. **Klik** "Simpan"

### Contoh Keywords
```
Keywords: ppdb, daftar, pendaftaran, cara daftar
Response: Untuk mendaftar PPDB, silakan kunjungi menu PPDB...
Category: ppdb
Priority: 10
```

### Melihat Chat History

1. **Klik** "Chatbot" → "Chat History"
2. **Lihat** riwayat percakapan
3. **Analisa** pertanyaan yang sering ditanyakan
4. **Tambah** response baru jika perlu

### Tips Chatbot
- ✅ Tambahkan keywords yang bervariasi
- ✅ Gunakan bahasa yang mudah dipahami
- ✅ Update response secara berkala
- ✅ Review chat history untuk improvement

## ❓ FAQ (Frequently Asked Questions)

### Q: Bagaimana cara mengganti password?
**A**: Klik nama Anda di top bar → Profile → Change Password

### Q: Gambar tidak muncul setelah upload?
**A**: Pastikan storage link sudah dibuat. Hubungi IT support.

### Q: Slider tidak tampil di homepage?
**A**: Pastikan slider sudah diset "Aktif" dan ada minimal 1 slider.

### Q: Bagaimana cara menghapus berita?
**A**: Buka detail berita → Klik tombol Delete → Konfirmasi

### Q: Notifikasi tidak muncul?
**A**: Refresh halaman atau clear browser cache.

### Q: Bagaimana cara backup data?
**A**: Hubungi IT support untuk backup rutin.

### Q: Lupa password admin?
**A**: Hubungi IT support untuk reset password.

### Q: Chatbot tidak merespon?
**A**: Pastikan ada response yang sesuai dengan keywords.

## 🆘 TROUBLESHOOTING

### Masalah Umum

#### 1. Tidak bisa login
- Cek username dan password
- Clear browser cache
- Coba browser lain
- Hubungi IT support

#### 2. Upload gambar gagal
- Cek ukuran file (max 2MB)
- Cek format file (JPG/PNG)
- Coba compress gambar
- Hubungi IT support

#### 3. Halaman error
- Refresh halaman
- Clear browser cache
- Coba lagi nanti
- Hubungi IT support

#### 4. Data tidak tersimpan
- Cek koneksi internet
- Pastikan semua field terisi
- Coba lagi
- Hubungi IT support
